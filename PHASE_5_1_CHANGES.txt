CREDNIVO PHASE 5.1 - DETAILED COLLECTION REPORT

Frontend
- Added Collection Report tab under Reports & Analytics.
- Added date range, quick range, cycle, status and customer/loan search filters.
- Added Expected, Collected, Pending, Fine and recovery summary.
- Added desktop detailed collection table and mobile collection cards.
- Added CSV export for the filtered detailed collection report.
- Added customer View action only when the logged-in account has customers.view permission.
- Added database loading/error status with safe fallback to currently synced workspace records.
- Reduced the report roadmap to the agreed first-launch scope only.

Backend
- Added GET /api/reports/collections?from=YYYY-MM-DD&to=YYYY-MM-DD&cycle=All|Daily|Weekly|Monthly.
- Endpoint is protected by reports.full through the existing AuthFilter.
- Returns company-scoped collection schedule rows, totals, status, fine, balance and latest payment date/mode.
- No database schema change is required.

Base
- Includes all Phase 5.0.4 frontend CSS/media modal fixes.
- Includes Phase 5.0.3 backend customer media permission/upload fixes.
