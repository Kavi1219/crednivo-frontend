CREDNIVO Frontend Phase 3.0 - PostgreSQL Backend Integration

Connected to the Spring Boot API already running on port 8080.

REAL DATABASE FLOW NOW ENABLED
- Customers load from PostgreSQL.
- New Customer saves with POST /api/customers.
- Customer profile photo uploads to the backend uploads folder.
- Customer KYC photo/PDF uploads to the backend.
- Jamin saves with PUT /api/customers/{id}/jamin.
- Jamin profile photo and KYC document upload to the backend.
- Loans load from PostgreSQL.
- New loans save with POST /api/loans.
- The backend creates the collection schedule and loan-disbursement payment record.
- Collections and payment history load from PostgreSQL.
- EMI and IO payments save through POST /api/payments/loan/{loanId}.
- Historical payment dates are sent to the backend.
- Customer deletion deletes the PostgreSQL customer and linked backend records.
- Customer/loan/payment/collection pages refresh from the backend after each write.

NETWORK BEHAVIOR
- Frontend API URL automatically follows the browser hostname.
  PC: http://localhost:5173 -> http://localhost:8080/api
  Phone: http://192.168.x.x:5173 -> http://192.168.x.x:8080/api
- npm run dev now exposes Vite on the local network automatically.
- Optional override: VITE_API_BASE_URL=http://your-server:8080/api

IMPORTANT
- Customers, loans, collections, payments and customer documents now use the backend as source of truth.
- Capital, Expenses, Agents, Company profile and their settings remain on the previous frontend storage for this phase and will be migrated next.
