CREDNIVO Frontend Phase 2.24

Overview metric card corrections:
- Zero-value cards now show 0% fill in the progress/target bar.
- Removed the old fixed half-filled appearance when the metric itself is zero.
- Collected Today progress is calculated from collected / expected.
- Pending / Overdue progress is calculated from pending / expected.
- Other cards keep their visual indicator only when they contain a non-zero value.
- Progress values are clamped safely between 0 and 100.
- Stat card text, numbers and notes now use consistent vertical alignment.
- Long titles wrap instead of being clipped.
- Wide desktop grids use a minimum card width so labels do not get squeezed.
- Collection Summary now has a correct empty state when Expected Today is zero (neutral donut, 0% values).
