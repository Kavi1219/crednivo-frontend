CREDNIVO Frontend Phase 3.4 - Agents, Documents & Company Profile DB

- Agents now load from /api/agents (PostgreSQL-backed).
- Invite, edit, approve, deactivate/status-edit, delete and agent profile photo upload added.
- Documents page now uses the existing document vault API for upload/list/view/download/delete.
- Documents can be linked to a customer or stored as company/general documents.
- Company profile now loads from /api/company.
- Company profile dropdown has Edit Company Profile with company logo/photo upload.
- Company name, Owner/MD, branch, mobile, email and address save to PostgreSQL.
- Existing Customers, Loans, Collections, Payments, Expenses, Capital, Dashboard and Reports integration preserved.
