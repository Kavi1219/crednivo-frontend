CREDNIVO FRONTEND PHASE 4.3 - OWNER CONFIGURABLE AGENT PERMISSIONS
=================================================================

- Owner -> Agents -> Permissions modal for each agent.
- Permission groups for Customers, Loans, Collections/Payments, Expenses,
  Documents, Reports, Capital and Overview.
- Sidebar, mobile drawer, mobile bottom nav and Quick Actions follow permissions.
- Page routes are permission guarded.
- Action buttons such as New Customer, Create Loan, Collect, Add Fine,
  Add/Edit/Delete Expense, document upload/delete and Capital management follow permissions.
- Customer Delete and payment/fine controls follow permissions.
- Settings are ALWAYS available to signed-in Owner and Agent for:
  * Light / Dark / System theme
  * English / Tamil language
  * Change own password
- Agent permissions refresh when the app/window becomes active again.
- Agents without capital.view do not see Available Capital on Overview/Today's Report.
- Today's Report can be granted without granting the Overview page.
- New Customer onboarding can finish after Jamin when loans.create is denied.
