CREDNIVO Frontend Phase 4.0 - Authentication & Roles

NEW
- First-run Owner security setup.
- Owner / Agent login tabs.
- Persistent JWT login session in localStorage.
- Authenticated API requests automatically send Bearer token.
- Owner-only route guards for Capital, Full Reports, Agents and Settings.
- Owner-only Company Profile editing and Customer deletion.
- Agent login supports Employee ID (EMP-xxx) or mobile number.
- Agent editor can create or reset an Agent login password.
- Agent cards show Login Ready / No Login.
- Header profile now shows signed-in role/account and supports Change Password + Logout.
- Desktop Sidebar and Mobile Drawer Logout are functional.
- Password change signs out active sessions.
- Expense creator now comes automatically from the signed-in account.
- Dark/light theme is applied to login/setup pages from existing CREDNIVO settings.
