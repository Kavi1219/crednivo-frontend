CREDNIVO Frontend Phase 2.22

Customer cleanup + delete customer

- Added a Delete Customer section at the bottom of Customer Profile.
- Added a confirmation popup before permanent deletion.
- Deleting a customer also removes that customer's linked loans, collections, payment records and customer/Jamin documents.
- Starter/demo customer data now contains only one customer.
- Added a one-time browser data cleanup for this phase: when the updated app first opens, existing frontend data is reduced to the most recently created customer (highest Customer ID), and all customer-linked data for the removed customers is deleted.
- The cleanup runs only once, so new customers can be added normally afterward.
- Company documents, expenses, capital entries, agents and settings are not removed.
- Delete UI follows Light/Dark/System themes and is responsive on mobile and desktop.
