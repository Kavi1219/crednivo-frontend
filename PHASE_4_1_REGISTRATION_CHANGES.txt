CREDNIVO Frontend Phase 4.1 - Simplified Registration

LOGIN PAGE
- Register Company button
- Register as Agent button
- Owner and Agent sign-in retained

COMPANY REGISTRATION
- Company Name
- MD / Owner Name
- Company Mobile
- Owner Mobile
- Company Email
- Branch Name / Location
- Address
- Company Logo / Photo
- Password + Confirm Password
- No OTP
- No email verification
- Direct Owner account creation on a fresh workspace

AGENT REGISTRATION
- Profile photo
- Agent Name
- Mobile
- Company Name
- Branch Name
- Password + Confirm Password
- No OTP
- No email acceptance
- Pending Owner Approval after submission
- Employee ID generated only after approval
- Agent can login with mobile or EMP ID after approval

OWNER AGENTS PAGE
- Approve and Reject buttons for pending self-registrations
- Password Saved state before approval
- Employee ID appears after approval

NOTE
CREDNIVO is currently a single-company workspace. If an Owner already exists,
the Company Registration page remains visible but a second company registration
is rejected by the backend.
