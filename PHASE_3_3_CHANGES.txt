CREDNIVO Frontend Phase 3.3 - Overview + Reports DB

- Overview metrics now come from GET /api/dashboard/today.
- Expected Today, Collected Today, Pending/Overdue, Upcoming 7 Days, Active Loans, Available Capital and Today's Expenses are backend-driven.
- Due customer count and upcoming customer count are backend-driven.
- Capital metrics now come from GET /api/capital/metrics.
- Collection Summary uses live backend pending/overdue figures.
- Today's Report uses backend dashboard metrics.
- Monthly Reports now load from GET /api/reports/monthly?year=YYYY&month=M.
- Report month switching fetches the selected month directly from PostgreSQL through Spring Boot.
- CSV export is generated from the backend report response.
- Existing professional report design and print layout are preserved.
